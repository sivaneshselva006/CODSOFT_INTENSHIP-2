# CODSOFT Task 3 — Secure Code Assessment

A beginner-friendly Python project for reviewing common security issues and demonstrating safer login-code practices.

## Requirements
- Python 3.9 or newer
- No third-party packages required

## Run
Open a terminal in this folder and execute:

```bash
python app.py
```

On Windows, `py app.py` may also work.
